# python-chapter2-practice

\# Python第二章课后练习

本仓库为《Python程序设计》第二章课后习题2.1\~2.8代码，包含单位转换、turtle图形绘制等程序。



\## 文件清单

| 文件名 | 题目说明 | 考查知识点 |

| ---- | ---- | ---- |

| 2\_1\_temp\_int.py | 2.1 温度转换，eval输入，输出整数温度 | eval()输入解析、字符串切片、if分支判断、类型转换 |

| 2\_2\_exchange.py | 2.2 美元与人民币双向兑换（1美元=6人民币） | 字符串切片识别单位、分支结构、数值计算、格式化输出 |

| 2\_3\_weight.py | 2.3 千克与英制磅双向转换（1kg=2.2046磅） | 分支判断、单位识别、浮点数运算、保留小数输出 |

| 2\_4\_color\_snake.py | 2.4 彩色蟒蛇绘制，每段画笔颜色变化 | turtle库基础、pencolor颜色设置、循环绘图 |

| 2\_5\_triangle.py | 2.5 绘制等边三角形 | turtle fd()前进、left()转向、for循环、角度计算 |

| 2\_6\_double\_tri.py | 2.6 叠加等边三角形（大三角+内部倒三角） | 抬笔penup()、落笔pendown()、循环、图形位置控制 |

| 2\_7\_sixstar.py | 2.7 六角形（大卫之星）绘制 | 循环绘图、角度控制、多个图形叠加思路 |

| 2\_8\_square\_spiral.py | 2.8 正方形螺旋线绘制 | 循环、变量自增、turtle连续转向绘图 |



\## 学习心得

通过第二章的8个小程序练习，我巩固了Python输入输出、分支判断的基础写法，理解了IPO程序设计思路。



\- 三道单位转换程序，我练习了eval()、字符串切片、if-elif分支，并学会从输入字符串里提取数值和单位，做双向换算，体会输入合法性判断的重要性；

\- turtle绘图系列练习让我熟悉了画笔前进、转向、抬笔落笔、修改颜色等API，理解循环在图形绘制里的价值：少量代码重复执行，就能画出规整几何图形；

\- 叠加图形、螺旋线的练习，重点锻炼了我对于角度、位置控制的逻辑，角度错一点，图形就会变形；

\- 本章还我初步接触了不同编程范式：过程式编程、生态式编程、面向对象编程，知道它们之间并不互斥，面向对象拥有更高的抽象级别。



调试代码时我发现，分支条件顺序、循环变量更新、角度计算都很容易出错。现阶段我重点感受\*\*过程式编程按步骤执行\*\*的思想，学会梳理程序逻辑，读懂代码执行流程，独立排查简单bug。
